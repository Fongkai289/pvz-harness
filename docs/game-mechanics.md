# 游戏静态参考与控制台

2026-10-30：`knowledge/pvz_mechanics.json` 保存 PvZ 1 PC 社区资料；当前 GOTY 1.2.0.1096 尚未逐项实测校准。

## 决策用途

`server/mechanics.py` 按已识别卡片、已种植物和僵尸种类，提供相关基础参数给 Planner 与 Jev。Planner 安排预算与火力，Jev 决定实际种植位置；不改变操作权限。资料独立于 playbook，不重写历史策略版本。

血量只用于规划：没有逐帧扣血或剩余血量跟踪。2026-11-02 起，System0 种子代码用这些满血数值粗估每行僵尸几秒到前排植物、几秒到家、现有火力几秒打完，写进 Jev 菜单和 Planner 上下文（`player_reference` 与种子 `seed_rows`，见 ARCHITECTURE.md 4.7）；这是按满血、不受阻挡的近似值，不是实时状态。基础血量含列出的护具，部分本体血量包含掉头后的濒死阶段，不能直接当成精确击杀弹数。速度是正常游戏速度下、无障碍时的近似秒/格；阶段列表不表示场上已观察到该阶段。

当前六张卡均有详细资料，另补充大嘴花、高坚果、南瓜头、大蒜、三种投手，以及 2026-11-02 补的双发射手（每次两颗 20 伤害的豌豆，间隔取豌豆射手的 1.425 秒；双发射手词条把这个间隔约写成 1.5 秒，并提到它偶尔先只打一颗）。研究环境支持的 8 种植物现在都有伤害数据。其他已知植物只提供已有阳光成本，并明确标记其余参数未核实。僵尸覆盖当前识别器支持的24种及 unknown；变体、不适用及无法核实的参数保留空值。

土豆雷资料存在14秒和15秒的表述差异，保留范围，15秒仅供留出准备距离。坚果约40秒仅适用于满血、单只普通僵尸以100 HP/s持续啃食；多个僵尸、减速、碾压和翻越会改变结果。普通植物无统一固定寿命。

来源链接和单位保存在 JSON 中，控制台“游戏图鉴”也展示。主要来源：[植物表](https://plantsvszombies.wiki.gg/wiki/Plants_%28PvZ%29)、[僵尸表](https://plantsvszombies.wiki.gg/wiki/Zombies_%28PvZ%29)、[伤害说明](https://plantsvszombies.wiki.gg/wiki/Damage)；具体植物和冷却资料见 JSON 的 sources。

## 控制台

首页展示网络往返、截图至点击端到端延迟、客户端 RSS 和对局应用上传/下载速率。模型表区分未触发、推理中、完成、失败，并列出调用耗时、周期、近60秒次数、累计和距触发时间。调用耗时包含服务端排队、模型推理及返回，不是纯GPU计算时间。

规划与决策、赛后复盘、当前策略和游戏图鉴分为独立页签。开始/暂停/继续/结束仍只控制客户端；结束保留窗口，右上角关闭才退出程序。暂停冻结调用统计；游戏菜单始终由操作员控制。

`GET /mechanics` 需 Bearer 认证，只返回公共资料；不读取游戏内存。测试覆盖资料边界、两层模型请求、端点认证及四按钮生命周期。

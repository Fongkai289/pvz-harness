截图：`docs/screens/main_menu.png`

**前提条件和注意事项**

- **显示缩放**：系统缩放是 175%。必须给 `PlantsVsZombies.exe` 设置"替代高 DPI 缩放行为 → 应用程序"（注册表 `AppCompatFlags\Layers` 里对应的值是 `~ HIGHDPIAWARE`，子进程 `popcapgame1.exe` 也会继承），客户区才是 800×600。如果不设置，Windows 会把游戏窗口放大，读到的客户区约是 1400×1050，坐标全错。另一种办法是把系统缩放改成 100%。
- **必须用窗口模式**：全屏模式下窗口一失去焦点就自动最小化，截不到图。在游戏选项里取消"全屏"。
  两种模式的窗口样式都带 `WS_POPUP`；窗口模式另外有标题栏 `WS_CAPTION`，按这一点区分。
- **游戏窗口不能被挡住**：mss 截的是屏幕上那块区域的像素，不是游戏窗口自己的画面，盖在上面的窗口会被截进去。跑智能体时要让游戏窗口露在最上面，别的窗口不能和它重叠。`verify_env.py` 第 2 项会检查遮挡。

- **四个角**：(0,0)、(4,0) 种向日葵，(0,8)、(4,8) 种坚果墙，全部正确（`landing_1-4/05、06、21、22`）。
- 1-4 里另有 4 次被脚本误判成"种上了"，实际没种（`landing_1-4/*_mismatch.png`，目标格子前后都是空的），不算点击错误。
  误判原因：收集的阳光往计数器飞的时候会划过卡片栏，脚本"看卡片有没有变暗"的判断就被干扰了。
  **对服务器识图的提醒**：读卡片状态（冷却中、阳光不够）时，飞过卡片栏的阳光会干扰判断，可能要多看几帧，或者避开有阳光飞过的那几帧。
- 第一次测的细节：点卡片 (120,43)，再点 `cell_center(2,0)` = (80,330)，豌豆射手正好落在第 2 行第 0 列，阳光 150 → 50。
- **游戏不在前台时的点击**：第一下点击就能生效（主菜单"开始冒险"直接被触发），但同时会把游戏切到前台。所以每次点击都会抢走焦点，游戏运行期间用户没法同时用别的窗口。
- **点击前必须确认点击位置真的在游戏窗口上**：pydirectinput 发的是屏幕坐标上的真实鼠标事件，游戏被挡住时点击会落到挡在上面的窗口里（这次测试时就有一下点到了 Claude 的窗口上，好在点到的是空白处）。
  建议 `windows_client.py` 在每次点击前用 `WindowFromPoint` 检查，不在游戏窗口上就拒绝点击，并报告错误。
- **游戏窗口要置顶**：在用户正常使用的桌面上，游戏很容易被别的窗口挡住，挡住时截图也会截错。测试时用了
  `SetWindowPos(HWND_TOPMOST)` 把游戏窗口置顶，之后截图和点击都正常。
- **游戏失去焦点就自动暂停**：用户一点别的窗口，游戏就弹出"GAME PAUSED"菜单，要点"Resume Game"(390,448) 或任意位置才继续。
  所以跑智能体期间游戏必须一直在前台，客户端（或服务器）要能识别暂停菜单并恢复，否则会对着暂停画面一直做决策。
  识别办法：画面中央 (260–540, 200–380) 的平均颜色 G < 90、B > G、亮度 < 70 就是暂停菜单；亮度 ≥ 70 是 Game Over 之类的对话框。
- 其他画面上的点击坐标（800×600）：Game Over 的"Try Again"在 (390,368)；"You got a new plant"页面的"Next Level!"在 (400,520)；
  过关奖励卡会掉在最后一只僵尸死掉的位置，要点它一下。

### 这次修改的客户端问题（`client/windows_client.py`）

- **游戏放在副屏上时点击失效**：`pydirectinput.click(x, y)` 只按主屏换算绝对坐标，游戏在副屏（坐标为负）时点不到。改成 `SetCursorPos` 加上按下和抬起。
- **点击时机**：鼠标移动后要等约 30 ms 再按下，否则按下会落在旧位置上。**菜单类按钮**（Menu、Restart Level、Resume 等）要先悬停约 0.3 s 才会响应；卡片和草坪等 30 ms 就够。
- **游戏失焦后自动暂停**：这一局最后约 45 秒，游戏因为失去焦点停在暂停菜单上，服务器一直在对着暂停画面做决策（planner 自己都说了"Game is paused"）。
  现在客户端检测到暂停菜单、并且不是操作员主动暂停时，会自动点"Resume Game"。
- **控制窗口**（新增）：放在游戏窗口旁边，有"暂停 / 继续 / 重玩本关 / 结束"四个按钮。暂停期间不上传帧，服务器发来的命令会被拒绝并回报。
  重玩本关会先结束当前会话，然后点 Menu (738,14) → Restart Level (398,355) → Restart (303,393)，再开一个新会话，所以每次尝试一个会话、日志分开。
  不传 `--seconds` 时一直运行，直到点"结束"。
- 游戏菜单对话框和暂停菜单颜色一样（都是深色石板），按颜色区分不开。所以重玩过程中关掉了自动解除暂停。
